# Stonevale — exploração livre

Nascimento aleatório nos Platôs Áridos, Cânions Profundos ou Vales Férteis Isolados.

Inclui calor, frio noturno, sede, água, coleta, escalada de cânion, miragens, acampamento, deslocamento livre, monstros hostis e consequências persistentes.

Execute \`instalar_stonevale.py\` dentro de \`rpg_aetheria\`.
