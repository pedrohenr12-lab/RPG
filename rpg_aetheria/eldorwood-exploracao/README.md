# Eldorwood — exploração livre

Nascimento aleatório na Floresta Densa Antiga, Pântanos e Rios ou Colinas Arborizadas.

Inclui neblina, chuva, frio, umidade, coleta segura, fogueira, travessia de pântano, Coruja-das-Brumas, fogo-fátuo, encontros sociais, fauna hostil, combate e consequências persistentes.

Execute \`instalar_eldorwood_exploracao.py\` dentro de \`rpg_aetheria\`.
