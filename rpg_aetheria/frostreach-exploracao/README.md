# Frostreach — exploração livre completa

Esta versão substitui a antiga sequência de cenas de Frostreach de maneira recuperável.

Inclui nascimento aleatório na Orla Costeira do Gelo, Planalto Central ou Presas de Gelo; frio, congelamento, fome, sede, fogueira, derretimento de neve, caça, pesca, escalada, sinais de civilização, monstros hostis e consequências persistentes.

Execute \`instalar_frostreach.py\` dentro de \`rpg_aetheria\`.
