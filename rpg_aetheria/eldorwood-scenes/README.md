# Eldorwood

Copie a pasta para dentro de `rpg_aetheria` e execute, no terminal aberto nessa pasta:

```powershell
py eldorwood-scenes/instalar_eldorwood.py
```

O pacote adiciona exploração lenta, fogueira, pesca, caça, coleta de ervas, fome/sede/energia, combate e escolhas persistentes. Inclui encontros de animais comuns, místicos e lendários, além de caminhos específicos para humano, elfo, anão, orc e draconato. Requer o pacote `mecanicas-rpg` instalado antes.
