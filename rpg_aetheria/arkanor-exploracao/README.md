# Arkanor — exploração livre

Nascimento aleatório nas Planícies Férteis, Colinas Suaves ou Vales Verdes.

Inclui exploração por direções, estradas, pessoas, reputação do reino, pesca, coleta, comida, sede, predadores, postos e rotas para civilização.

Execute \`instalar_arkanor.py\` dentro de \`rpg_aetheria\`.
