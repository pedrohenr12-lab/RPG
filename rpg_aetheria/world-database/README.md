# Banco narrativo

Copie esta pasta para `rpg_aetheria/` e execute:

```powershell
py world-database/instalar_banco_mundo.py
```

Ele instala dados de Eldorwood, criaturas, biomas e o diário de descobertas do personagem. As próximas cenas podem consultar `engine.world_database` para gerar encontros válidos por bioma.
