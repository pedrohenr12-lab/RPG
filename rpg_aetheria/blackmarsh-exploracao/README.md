# Blackmarsh — exploração livre

Nascimento aleatório nos Pântanos Vastos, Mangues Gigantes ou Ilhas de Vegetação Flutuante.

O sistema traz calor, umidade, sede, água insegura, toxinas, fogo-fátuo, acampamento, coleta, deslocamento por direções, encontros sociais, monstros hostis e consequências persistentes.

Execute `instalar_blackmarsh.py` dentro de `rpg_aetheria`. Ele preserva cópias de segurança dos arquivos que alterar.
